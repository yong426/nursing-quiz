# 간호조무사 모의 문제은행

간호조무사 국가시험 대비 **자체 제작 모의문제 1,349문항** 학습용 웹앱.

- 국가시험 형식 그대로: 5지선다, 과목별 문제은행 (기초간호학 개요 464 · 보건간호학 개요 192 · 공중보건학 개론 288 · 실기 405)
- **과목·세부주제(27개)·난이도 멀티셀렉트** → 무작위 출제
- 상단 탭 4개(문제 풀이 / 실전 모의고사 / 오답노트 / 학습 기록)로 화면 분리
- **실전 모의고사** 105문항 (2025 CBT 개편 기준: 35/15/20/35 배분, 105분 타이머·시간 종료 시 자동 채점, 총점 60%·과목별 40% 합격 판정, 과락 표시)
  - **난이도**: 노멀(기출 7개 회차 700문항 분석 결과를 과목별로 재현) / 하드(전 과목 쉬움 20%·중간 50%·어려움 30% 고정)
  - **채점 방식**: 바로 채점(문항마다 정답·해설 즉시) / **종료 후 채점**(실제 CBT처럼 시험 중 정답 비공개 — 건너뛰기, 이전·다음 이동, 답안지에서 번호 클릭 점프, 답 변경, 제출 시 일괄 채점, 답 선택 시 자동으로 다음 문항)
  - 실제 시험과 같은 **과목 순서**(기초 1~35 → 보건 36~50 → 공중 51~70 → 실기 71~105)
- **중간 저장 & 정지** — 두 채점 방식 모두 지원. 남은 시간·응답까지 저장되고 홈에서 '이어서 풀기'
- **버전 자동 갱신** — `version.json`을 확인해 새 버전이면 설정·중간저장만 비우고 최신 UI로 자동 새로고침 (오답노트·학습기록·누적통계는 보존)

## 배포 시 주의

기능·UI를 바꾸면 `index.html`의 `APP_VERSION`과 `version.json`의 `app`을 **같은 값으로** 올린다.
`data.js`를 바꾸면 `index.html`의 `data.js?v=` 값과 `version.json`의 `data`도 함께 올린다.
- **난이도 필터** (쉬움/중간/어려움) — 전 문항 난이도 태깅
- **보기 순서 무작위** — 같은 문항을 다시 풀어도 위치로 답을 외우지 못하게 매 세션 보기를 섞는다
  (보기가 전부 짧은 수치이고 이미 정렬된 문항은 실제 시험 관행대로 순서 유지)
- **오답노트 과목별 필터** + 과목별 다시 풀기
- **세션별 상세 기록** — 학습 기록·모의고사 결과에서 세션을 누르면 과목별·난이도별 점수 확인
- 즉시 채점 + 해설
- **오답노트**: 자동 저장, 다시 풀기, 맞히면 자동 제거
- **학습 기록**: 세션 이력, 과목별 누적 정답률
- 데이터는 브라우저 localStorage에 저장 (기기별)

## 안내

본 문제은행의 모든 문항과 해설은 시험 형식에 맞춰 **새로 창작한 학습용 모의문제**입니다.
실제 국가시험 기출문제가 아니며, 내용에 오류가 있을 수 있으므로 참고용으로만 활용하세요.
