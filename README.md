# 간호조무사 모의 문제은행

간호조무사 국가시험 대비 **자체 제작 모의문제 1,349문항** 학습용 웹앱.

- 국가시험 형식 그대로: 5지선다, 과목별 문제은행 (기초간호학 개요 464 · 보건간호학 개요 192 · 공중보건학 개론 288 · 실기 405)
- **과목·세부주제(27개)·난이도 멀티셀렉트** → 무작위 출제
- 상단 탭 4개(문제 풀이 / 실전 모의고사 / 오답노트 / 학습 기록)로 화면 분리
- **실전 모의고사** 105문항 (2025 CBT 개편 기준: 35/15/20/35 배분, 105분 타이머·시간 종료 시 자동 채점, 총점 60%·과목별 40% 합격 판정, 과락 표시)
  - **노멀 모드** — 기출 7개 회차(700문항) 난이도 분석 결과를 과목별로 재현 (실전 체감)
  - **하드 모드** — 전 과목 쉬움 20% · 중간 50% · 어려움 30% 고정 (기출보다 어려운 훈련용)
- **난이도 필터** (쉬움/중간/어려움) — 전 문항 난이도 태깅
- **오답노트 과목별 필터** + 과목별 다시 풀기
- **세션별 상세 기록** — 학습 기록·모의고사 결과에서 세션을 누르면 과목별·난이도별 점수 확인
- 즉시 채점 + 해설
- **오답노트**: 자동 저장, 다시 풀기, 맞히면 자동 제거
- **학습 기록**: 세션 이력, 과목별 누적 정답률
- 데이터는 브라우저 localStorage에 저장 (기기별)

## 안내

본 문제은행의 모든 문항과 해설은 시험 형식에 맞춰 **새로 창작한 학습용 모의문제**입니다.
실제 국가시험 기출문제가 아니며, 내용에 오류가 있을 수 있으므로 참고용으로만 활용하세요.
