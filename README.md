# 간호조무사 모의 문제은행

간호조무사 국가시험 대비 **자체 제작 모의문제 1,369문항** 학습용 웹앱.

## 기능

- 국가시험 형식 그대로: 5지선다, 과목별 문제은행 (기초간호학 개요 464 · 보건간호학 개요 192 · 공중보건학 개론 308 · 실기 405)
- 상단 탭 4개(문제 풀이 / 실전 모의고사 / 오답노트 / 학습 기록)로 화면 분리
- **과목·세부주제(27개)·난이도 멀티셀렉트** → 무작위 출제
  - 선택 범위 안에서 실전 배분(과목 35/15/20/35 → 난이도 20/50/30 → 세부주제 비례)으로 3단 층화 추출
  - 선택하지 않은 과목·난이도는 제외하고 남은 항목으로 비율을 다시 맞춤
- **실전 모의고사** 105문항 (2025 CBT 개편 기준: 35/15/20/35 배분, 105분 타이머·시간 종료 시 자동 채점,
  총점 60%·과목별 40% 합격 판정, 과락 표시, 미응답은 오답 처리)
  - **난이도 모드**: 노멀(기출 7개 회차 700문항 분석 결과를 과목별로 재현) / 하드(전 과목 쉬움 20%·중간 50%·어려움 30% 고정)
  - **채점 방식**: 바로 채점(문항마다 정답·해설 즉시) / **종료 후 채점**(실제 CBT처럼 시험 중 정답 비공개 —
    건너뛰기, 이전·다음 이동, 답안지에서 번호 클릭 점프, 답 변경, 제출 시 일괄 채점, 답 선택 시 자동으로 다음 문항)
  - 실제 시험과 같은 **과목 순서**(기초 1~35 → 보건 36~50 → 공중 51~70 → 실기 71~105), 과목 내부만 무작위
- **보기 순서 무작위** — 같은 문항을 다시 풀어도 위치로 답을 외우지 못하게 매 세션 보기를 섞음
  (보기가 전부 짧은 수치이고 이미 정렬된 문항은 실제 시험 관행대로 순서 유지)
- **중간 저장 & 정지** — 두 채점 방식 모두 지원. 남은 시간·응답·보기 순서까지 저장되고 홈에서 '이어서 풀기'
  (난이도·채점 방식이 다른 모의고사는 각각 별도 슬롯에 보관)
- **복습 탭** — 오답노트와 별표를 분리해 보관, 각각 과목·난이도 필터와 '필터 결과만 다시 풀기' 지원
  - **오답노트**: 틀리면 자동 저장, 다시 풀어 맞히면 자동 제거(설정)
  - **★ 별표**: 잘 몰라서 찍은 문항을 정답·오답과 무관하게 표시 — 문제 카드의 ☆ 버튼으로 토글,
    해설 화면에서도 표시 가능, 별표만 모아 다시 풀기
- **학습 기록** — 세션 이력과 과목별 누적 정답률, 세션을 누르면 과목별·난이도별 상세 점수
- **버전 자동 갱신** — `version.json`을 확인해 새 버전이면 설정·중간저장만 비우고 최신 UI로 자동 새로고침
  (오답노트·학습기록·누적통계는 보존)
- 모든 학습 데이터는 브라우저 localStorage에 저장 (기기별)

## 문항 추가

`tools/` 폴더 참고. 생성 프롬프트, 교차 검수 프롬프트, 검사·병합 스크립트, 1,000문항 추가 계획이 들어 있다.

## 배포 시 주의

기능·UI를 바꾸면 `index.html`의 `APP_VERSION`과 `version.json`의 `app`을 **같은 값으로** 올린다.
`data.js`를 바꾸면 `index.html`의 `data.js?v=` 값과 `version.json`의 `data`도 함께 올린다.
(`tools/merge.py`로 병합하면 이 세 값이 자동으로 올라간다.)

푸시는 두 브랜치에 함께: `git push origin main main:gh-pages`

## 안내

본 문제은행의 모든 문항과 해설은 시험 형식에 맞춰 **새로 창작한 학습용 모의문제**입니다.
실제 국가시험 기출문제가 아니며, 내용에 오류가 있을 수 있으므로 참고용으로만 활용하세요.
