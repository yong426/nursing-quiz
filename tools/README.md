# Gemini(또는 다른 모델)로 문항 늘리기 — 작업 가이드

## 먼저 알아야 할 것: 구독과 API는 별개다

| 원하는 것 | Google AI Pro 구독으로 되는가 | 방법 |
|---|---|---|
| Gemini 앱에서 대화로 문항 생성 | **된다** (구독의 핵심 혜택) | 아래 **경로 B** |
| 에이전트가 파일을 읽고 쓰며 자동 생성 | **된다** — Antigravity에 Pro 할당량이 붙는다 | 아래 **경로 A** |
| 코드에서 `gemini-api` 호출 (API 키) | **안 된다** — API는 별도 과금(AI Studio) | 아래 **경로 C** |

- Gemini CLI에 구글 계정으로 로그인해 쓰던 방식은 **2026년 6월 18일로 종료**됐다. Antigravity로 이전됐다.
- 즉 "Claude Code처럼 구독으로 에이전트를 돌리는" 그림은 **Antigravity**가 대응 제품이다.

---

## 경로 A — Antigravity (구독 활용 + 자동화, 권장)

1. [antigravity.google](https://antigravity.google/) 에서 Antigravity를 설치하고 **AI Pro를 구독한 구글 계정으로 로그인**한다
   (무료 개인 플랜도 쓸 수 있고, Pro 구독이면 속도 제한이 완화된다).
2. 이 리포 폴더(`nursing-quiz`)를 열고 에이전트에게 이렇게 지시한다:

   ```
   tools/prompt_generate.md 를 읽고, 그 규칙에 따라 "[[주제]]" 문항 30개를 만들어
   tools/incoming/nq3_<주제>.json 에 저장해라.
   저장 후 `python tools/validate.py tools/incoming/nq3_<주제>.json` 을 실행해
   오류가 0이 될 때까지 스스로 고쳐라.
   ```
3. 검수(**필수**, 아래 3단계)를 거친 뒤 `python tools/merge.py` 로 병합한다.

## 경로 B — Gemini 앱에 붙여넣기 (설치 없이 지금 바로)

1. `tools/prompt_generate.md` 를 열고 `[[...]]` 를 채운다 (주제·개념·문항수·목표 난이도).
2. [gemini.google.com](https://gemini.google.com/) 에 붙여넣는다. 한 번에 **20~40문항**이 안정적이다.
3. 출력된 JSON 배열을 `tools/incoming/nq3_<주제>.json` 으로 저장한다.
   (앞뒤에 설명이 붙어 나오면 `[` 부터 `]` 까지만 남긴다.)
4. 3단계 검수 → 병합.

## 경로 C — Gemini API (완전 자동화가 꼭 필요할 때)

[aistudio.google.com](https://aistudio.google.com/) 에서 API 키를 발급한다. **AI Pro 구독과 무관하게** 별도
무료 한도가 있고, 초과분은 Google Cloud로 과금된다. 무료 한도만으로도 이 작업은 충분한 편이지만,
한도·모델명·가격은 자주 바뀌니 발급 화면에서 현재 값을 확인할 것. 키는 절대 리포에 커밋하지 말고
환경변수로 넘긴다.

## 문항을 늘리는 3단계 (경로와 무관하게 공통)

### 1단계 — 생성
`tools/prompt_generate.md` 규칙대로 만든다. 규칙에는 이 문제은행에서 실제로 사고가 났던 항목이 반영돼 있다:
- 오답 보기를 **정답과 같은 범주의 실제 항목**으로 (비상식적 오답 → 지식 없이 풀리는 쉬운 문항이 된다)
- 그러나 **정답과 동등하게 옳은 보기 금지** (복수 정답 — 가장 흔한 결함)
- **교재별로 갈리는 값은 출제 금지** (손씻기 시간, 경관영양액 "체온", 남성 도뇨 삽입 길이 등 목록 참고)

### 2단계 — 검수 (건너뛰지 말 것)
`tools/prompt_verify.md` 를 **생성에 쓰지 않은 다른 모델**에 붙여넣는다.
Gemini로 만들었으면 Claude로, Claude로 만들었으면 Gemini로. 같은 모델은 자기가 놓친 오류를 또 놓친다
(실측: 이 은행의 215문항 검수에서 교차 검수로만 복수 정답 결함 2건이 잡혔다).
지적된 문항은 고치거나 삭제한 뒤 다음 단계로.

### 3단계 — 검사 · 병합 · 배포
```bash
python tools/validate.py tools/incoming/*.json      # 스키마·중복·위험표현 검사
python tools/merge.py tools/incoming/*.json --dry-run   # 결과 미리보기
python tools/merge.py tools/incoming/*.json         # data.js 갱신 + 버전 자동 상향
git add -A && git commit -m "문항 추가" && git push origin main main:gh-pages
```
`merge.py` 가 `index.html`의 `APP_VERSION`·`data.js?v=` 와 `version.json` 을 함께 올리므로,
기기에서 앱을 열면 자동으로 최신 문항이 반영된다.

병합 후 출력되는 **모드 쿼터 충족 여부**를 확인할 것. "부족"이 뜨면 해당 과목·난이도 문항이
모의고사 1회분보다 적다는 뜻이므로 그 칸을 더 만들어야 한다.

## 난이도 태그(`d`)에 대해

`d`는 생략하면 **2(중간)** 로 들어간다. 실전 모의고사가 과목×난이도 쿼터로 뽑기 때문에
난이도 분포가 한쪽으로 쏠리면 출제가 편향된다. 정확히 하려면 병합 전에
`tools/prompt_verify.md` 를 쓴 그 모델에게 난이도 판정을 함께 요청해 `d`를 채워라:

```
아래 문항들의 난이도를 1(쉬움)/2(중간)/3(어려움)으로 판정해 {"0":2,"1":3,...} 형태로만 출력하라.
기준 — 1: 기본 정의를 직문직답, 오답이 명백히 동떨어짐 / 2: 사례 적용 또는 인접 개념 감별, 오답 1~2개가 그럴듯함
/ 3: 정확한 수치·기간·예외 암기 필요, 또는 보기 다수가 유사해 미세 감별 필요
발문만 보지 말고 오답이 얼마나 헷갈리는지를 함께 볼 것.
```

## 현재 상태 (참고)

- 문제은행 1,349문항 = 기초 464 · 보건 192 · 공중 288 · 실기 405
- 난이도 = 쉬움 806 · 중간 447 · 어려움 96
- 기출 실측 난이도 분포는 쉬움 50 · 중간 39 · 어려움 10%인데 우리 은행은 60/33/7 이므로,
  **중간·어려움 문항을 늘리는 것이 가장 효과가 크다.** 특히 공중보건학(의료법규·역학)이 약점 과목이다.
