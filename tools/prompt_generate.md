## 목표 난이도
**[[중간]]** — 아래 정의를 따른다.
- **쉬움**: 기본 정의·단일 사실을 직문직답으로 묻고, 오답이 명백히 동떨어져 상식만으로 소거 가능
- **중간**: 개념을 사례에 적용하거나 인접 개념(소독 vs 멸균, 자격정지 vs 면허취소)과 감별해야 하며, 오답 중 1~2개가 그럴듯함
- **어려움**: 정확한 수치·기간·예외 조항 암기가 필요하거나, 보기 여러 개가 모두 그럴듯해 미세 감별이 필요하거나, 2단계 이상 추론이 필요

## 출제 규칙
1. **완전 창작**: 실제 기출문제 복원 시도 금지, 특정 교재·문제집·웹사이트 문구 재현 금지. 너의 지식으로 새로 써라.
2. **5지선다, 정답 정확히 1개.** 한국 간호조무사 국가시험 수준. 표준 교과서 수준의 정설만 출제하고,
   교재·기관마다 갈리거나 확신이 없는 수치·법조항은 **출제하지 마라**(아래 금지 목록 참고).
3. **오답 보기는 정답과 같은 범주의 실제 항목**으로 구성한다. 정답이 체위면 오답도 실제 쓰이는 체위,
   정답이 온도값이면 인접 온도값, 정답이 술기 규칙이면 다른 술기의 실제 규칙.
   ⚠ 오답을 "명백히 유해하거나 비상식적인 행위"로 채우면 지식 없이도 소거되는 쉬운 문항이 된다. 금지.
   ⚠ 그러나 **정답과 동등하게 옳은 보기를 만들면 절대 안 된다**(복수 정답). 이것이 최대 금기다.
4. 사례형("간호조무사가 ~하고 있다") 절반 이상, 부정형("옳지 않은 것은?") 20% 이하.
5. "모두 옳다 / 모두 틀리다"류 보기 금지. 보기 5개는 서로 배타적으로.
6. 정답 번호(1~5)를 고르게 분산한다.
7. `exp`(해설): 2~3문장 한국어 평서체(-이다/-한다). ① 정답 근거 ② 가장 그럴듯한 오답 1개를 짚어 왜 아닌지 구분.

## 출제 금지 — 교재별로 값이 갈리는 항목
아래는 국내 교재·지침 간 서술이 달라 정답 시비가 생긴다. **정답이나 오답의 판별 근거로 쓰지 마라.**
- 내과적 손씻기 **시간**(교재별 10~15초 / 15초 / 15~30초 / 40~60초로 갈림) → 시간 대신 방향·절차 오류를 쓸 것
- 경관영양액 온도를 "체온"으로 단정(근거지침은 "차갑지 않은 실온")
- 단순도뇨 남성 삽입 길이 20cm·18~20cm(표준은 12~18cm), 소변 후 추가 삽입 "2~3cm"(표준 2~4cm)
- 더운물주머니 50~60℃(표준: 성인 46~52℃, 무의식·소아·노인 40.5~46℃)
- 억제대 여유 "손가락 1개"만 정답 처리(1~2개로 갈림)
- 고막체온 이개 견인 방향을 경계 나이(만 3세)로 묻기 → 18개월 등 경계에서 벗어난 나이를 쓸 것
- 개정이 잦은 법령 세부(벌칙 금액, 최근 개정 조항)

## 출력 형식
**설명·머리말 없이 JSON 배열만** 출력하라. 코드블록도 쓰지 마라.

```
[
 {"t":"[[주제 라벨]]","q":"문제 발문","c":["보기1","보기2","보기3","보기4","보기5"],"ans":3,"exp":"해설"},
 ...
]
```

- `t`는 아래 27개 중 **정확히 하나**를 문자열 그대로 쓴다:
  기초간호학 개요 → `간호관리·윤리·역사` `해부생리(구조·신경·감각)` `해부생리(내장기관)` `성인간호(내과)` `성인간호(외과·수술)` `모성간호` `아동간호` `노인간호` `약물·영양` `치과·한방`
  보건간호학 개요 → `보건행정·의료보장` `보건교육·산업보건` `모자보건·지역사회·방문`
  공중보건학 개론 → `감염병·역학` `환경·식품위생` `인구·통계·건강증진` `의료법규(의료법)` `의료법규(관계법규)`
  실기 → `활력징후·신체계측` `감염관리·무균술` `투약·검체` `위생·체위·안전` `배뇨·배변` `영양·식사돕기` `상처·붕대·열냉요법` `산소·흡인·호흡` `응급처치·CPR`
- `ans`는 1~5 정수, `c`는 정확히 5개.
- 정확히 **[[30]]개** 항목을 출력한다.
